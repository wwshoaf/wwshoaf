## 🔬 Recent Projects

### [WV Disease Underreporting Detection](https://github.com/wwshoaf/Big-Data-Engineering-Disease-Underreporting-Detection)
Detects statistically anomalous gaps between predicted and reported Lyme disease and Chlamydia
rates across all 55 West Virginia counties. Uses Census Bureau SDoH data pulled live via API,
Random Forest regression with Leave-One-Out cross-validation, and Isolation Forest anomaly
detection — with choropleth mapping of underreporting hotspots and a 2023–2024 stability check
to rule out demographic confounds.
`PySpark` `Apache Spark` `Scikit-learn` `GeoPandas` `Census API`

---

### [Mushroom Edibility Classification: Tabular ML vs. ResNet18](https://github.com/wwshoaf/Mushroom-Edibiility-Classification-Method-Comparison)
Structured comparison of six tabular classifiers against CNN image classification for predicting
mushroom edibility — both constrained to field observable features. Tabular
models (RF, MLP) reach 99.99% accuracy vs. ResNet18 at 83.4%, with a 15+ point gap suggesting
structured feature engineering dominates raw image signal for this domain.
`Python` `PyTorch` `Scikit-learn` `XGBoost` `ResNet18`

---

### [Network Intrusion Detection System](https://github.com/wwshoaf/Advanced-Networking-AI-IDS-Project)
ML-based IDS pipeline built on the CIC-IDS2017 dataset, comparing Logistic Regression, Random
Forest, and MLP classifiers with an automated threat response engine. Critically evaluates
real-world deployment limitations including lab-traffic inflation and temporal leakage.
`Python` `Scikit-learn` `Pandas` `Network Security`

---

### [Allied Ants — Yoga Studio Management System](https://github.com/wwshoaf/AlliedAnts)
Full-stack web application for yoga studio management built with Flask and MySQL — schema design, stored procedures, scheduling, and client data management.
`Flask` `MySQL` `Python` `HTML/CSS`
